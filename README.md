#### 2.2 Планирование производства

Заменяет Google-таблицу, в которой планировщик распределяет SKU по станкам КП1–КП5.

Состав:
- Модель `ProductionPlan` + `PlanLine`.
- Калькулятор времени производства заданного объёма на заданном станке.
- Границы применимости SKU × станок.
- Связь с PrintRun (оператор печатает по плану).
- Гибкие единицы измерения плана: штуки / работа всю смену / «сработать ПФ под ноль».

Статус: идёт сбор требований (опрос планировщика).

#### 2.8 Контроль качества

Регламент периодичности проверок, навязываемый через ТСД.

Состав:
- Триггер по количеству пакетов (порог в `Specification`, дефолт 1000).
- Счётчик по станку с обнулением при смене упаковщика.
- ТСД требует проверку при достижении порога — блокирует дальнейшее сканирование.
- Проверка не выполнена в течение 15 минут → статус `missed`.
- Отдельный эндпоинт `GET /reports/quality`.
- Строка сводки в отчёте смены.

Статус: спецификация готова, ждёт реализации.

#### 4.1 Веб-конструктор макетов этикеток

План интеграции:
1. Берём QR Layout Tool (лицензия MIT).
2. Встраиваем в репозиторий как отдельный модуль фронтенда.
3. Используем только для визуального дизайна и сохранения JSON-макета.
4. TSPL генерируется на бэкенде из JSON.
5. Сценарий: новый клиент → конструктор → перетаскивание элементов → сохранение → привязка к спецификации.

Условие запуска: наличие готового веб-интерфейса (Уровень 3) как платформы.

### Что уже работает

Сквозной цикл производства:
Утро → Оператор открывает смену
→ Упаковщик регистрируется на станке (ТСД)
→ Оператор печатает партию этикеток (PrintRun)
→ Упаковщик клеит → сканирует → коробка labeled
→ Коробки собираются на виртуальную паллету
→ Паллета закрывается
Вечер → Оператор закрывает смену
→ Все открытые паллеты закрываются автоматически
→ Отчёт: сколько сделано, кем, на каком станке

Возможности системы:
- Каждая коробка имеет уникальный UID навсегда.
- Каждая этикетка читается мобильным телефоном.
- Каждый скан привязан к упаковщику и станку.
- История операций не удаляется.
- Отчёт по смене формируется за секунды.

Что пока не реализовано:
- Планирование производства.
- Учёт сырья.
- Контроль качества на ТСД.
- Веб-интерфейсы для операторов.
- Клиенты как сущности.
- Отгрузка и документы.
